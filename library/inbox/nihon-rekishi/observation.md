# observation: nihon-rekishi（60秒でわかる日本の歴史）

出典：claude.ai artifact（自社制作）。ステージ 1280×720（16:9）を CSS transform で縮小して表示している。
数値は `source.html` と `extract-report.json` から読んだもの。「推定」と書いたもの以外はコードで確かめた値。

## 構成
- はじめのカード 2.6s → 時代シーン 15枚 × 3.6s → おわりのカード 3.2s ＝ 59.8s
- 時代シーンはすべて同じ骨組みで、背景色・イラスト・文字だけが入れ替わる

## 動き
シーン切り替えから文字が出そろうまで、4段に分かれた順番で動く。

| 時刻 | 対象 | 動き | 時間 | カーブ |
|---|---|---|---|---|
| 0ms | シーン全体 | clip-path で右から左に開くワイプ `inset(0 0 0 100%)→inset(0)` | 550ms | cubic-bezier(.7,0,.2,1)（ゆっくり出て速く入り、最後はゆるやか） |
| 150ms | 背景の円（disc） | `scale(.4) rotate(-8deg)`・透明 → 通常 | 600ms | cubic-bezier(.3,1.5,.5,1)（行き過ぎて戻る） |
| 300ms | イラスト（SVG） | 同上 | 700ms | cubic-bezier(.3,1.6,.5,1)（円より少し強く行き過ぎる） |
| 300 / 380 / 520 / 660ms | 番号 / 時代名 / 年代 / 説明 | `translateY(50px)`・透明 → 通常 | 各500ms | cubic-bezier(.2,.9,.3,1.2)（わずかに行き過ぎる） |

- 文字4段の間隔は 80 / 140 / 140ms。番号と時代名はほぼ同時、年代と説明は少し間を置く
- 円→イラストは 150ms ずらし。イラストの方が長く・強く弾むので、円が「台座」、イラストが「主役」に見える
- 退場の動きはない。次のシーンのワイプが前のシーンの上にかぶさって消える。登場と退場は非対称
- はじめ／おわりのカードも同じ pop と rise の組み合わせ（日の丸 100ms・1.6、見出し 300ms 550ms、補足 550ms）。時代シーンと同じ部品なので別に取り出さない
- `prefers-reduced-motion` のときはすべての動きを止める配慮がある

## 文字
- 見出し（時代名）：Dela Gothic One 400、190px、字間 -0.02em、行間 1.05。2字で左の画面半分ほど
- 本文（説明）：Zen Kaku Gothic New 700、38px、行間 1.45、字間 0、1行の最大 15em（15字）
- 見出し:本文 = 190:38 = 5.0
- 補助：番号 26px 700 字間 0.04em・不透明度 .7、年代 40px 700 アクセント色
- 見出しのサイズは `var(--es,190px)` で、JS から `--es` を入れる所はない。時代名はすべて2字なので、実際に使われたのは 2字=190px だけ
- 3字以上の自動縮小は推定：文字の列の幅は 1280−70−90−560−30 = 530px。190px×2字 ≒ 372px。3字 150px（≒441px）、4字 120px（≒470px）、5字以上 96px（5字 ≒ 470px）なら 530px に収まる
- フォントは両方とも Google Fonts の SIL OFL

## 配置
- 16:9、`grid-template-columns: 560px 1fr`、padding 上0 右90 下0 左70、上下中央そろえ
- 左の列に 460px の円（中に 380px のイラスト）、右の列は左そろえで 番号／時代名／年代／説明 の4段
- 余白の比率：左 70 : 右 90。右を広くして文字が画面の端に寄りすぎないようにしている
- カードは1列・中央そろえ（時代シーンと別の骨組みだが、日の丸＋大見出しの定番なので今回は取り出さない）

## 図像
- 15枚すべて viewBox 0 0 200 200、塗り中心、グラデーション・影なし
- 色数：縄文 2、弥生 6、奈良 1 は §4③ の 3〜5色のルールから外れる。それ以外の12枚は 3〜5色
  - 縄文：土器の下に接地の楕円を足して3色にする
  - 弥生：梁の #5E4522 を柱の #6B4A2B にまとめて5色にする
  - 奈良：1色の線画（平城京の碁盤目）。区画を2色で塗り分け、大路と宮域を分けて3色にする
- 線を使っている図（弥生・平安・鎌倉・戦国・江戸・明治・大正・令和）は stroke-linecap が round でない所があるので round にそろえる
- 室町の水面の反射だけ opacity .35 を使っている（フィルターではないので許容）
- 平成は `transform="rotate(-12 100 100)"` で傾けている
- 図像は背景の円（背景より少し明るい色）の上に置く前提なので、色は背景とも円とも別の色を選んでいる

- 背景は1色のベタ。disc は背景と同じ色相（±2°）で、明度だけ常に**明るい側に** +5〜10。指示書の例「±6%」とは違い、暗くする例はない
- ink は背景が暗いときは生成り（#F3EBDD 前後）、明るいときは背景と同じ色相のごく暗い色
- acc は彩度が高い（56〜100%）。補色寄り（色相差 100°以上）は縄文・飛鳥・鎌倉・室町・江戸・明治・令和の7つ。残りは同系色の濃い色
- ink:bg が 7:1 に届かないのは6時代（太字）。奈良 4.52 は大きな文字の最低ライン（WCAG AA）ぎりぎり
  - 登録する規則は 7:1 を保つ。例として載せるのは 7:1 を満たす9時代だけ
  - 届かない6時代の直し方（案、計算で 7:1 を確認済み）
    - 古墳：ink #1F2A12 → #1E2911（7.00）。ほぼ変わらない
    - 平安：ink #2A1E3C → #261B37（7.05）
    - 明治：ink #15191C → #111417（7.03）
    - 大正：ink #2A1418 → #200F12（7.05）
    - 奈良：ink は生成りのままでは白にしても届かないので、背景を #C73A33 → #932B26（7.05）に暗くする。disc も同じだけ暗くする
    - 室町：同じく背景を #3E6450 → #355645（7.06）に暗くする
- acc:bg は大正だけ 2.30。年代（40px 700）に使うので、大きな文字の 3:1 を acc の最低ラインとする

## 間
- 時代シーン 3.6s のうち、動いているのは 0〜1.16s（説明文の rise が終わるまで）。1.16 / 3.6 ≒ 0.32 → 動き 0.33 : 静止 0.67
- 動きは前半1/3に集中していて、残りの約2.4秒はナレーションを聞かせるために止まっている
- はじめのカード 2.6s・おわりのカード 3.2s は、時代シーンより短い／長いことで区切りを作っている（推定の意図）
